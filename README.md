# flashcard-game
A flashcard game with lives, and lives. For someone wanting to gamify what they are learning.

##  Description

I wanted to gamify some learning, there are a bunch of flashcard apps, but I enjoy the thought of a true video game experience.

## Installation 

Clone repository:
```
git clone https://github.com/TrueCloo/flashcard-game.git
```

cd into folder:
```
cd flashcard-game
```

Download requirements:
```
pip install -r requirements.txt
```
(On macOS, use pip3 if pip isn't found.)

Start flask app in terminal:
```
flask run 
```
Then open http://127.0.0.1:5000 in your browser.
